# Task 3: Interactive Dashboard

## 📌 Project Overview

This project was completed as **Task 3 of my Data Analyst Internship at SWYNEX Technologies**.

The objective of this task was to transform the insights obtained from the cleaned Titanic dataset and SQL-based exploratory analysis into an interactive and easy-to-understand dashboard.

The dashboard presents key performance indicators, survival analysis, visualizations, and interactive filters.

---

## 🎯 Objectives

- Create an interactive data analytics dashboard
- Present important business-style KPIs
- Visualize Titanic survival patterns
- Make the analysis easier to understand
- Provide filters for interactive exploration
- Communicate the key findings from the previous SQL analysis

---

## 📊 Dataset

**Dataset:** Titanic Dataset

The dashboard is based on the cleaned Titanic dataset prepared during:

- **Task 1:** Data Cleaning & Preparation
- **Task 2:** Exploratory Data Analysis Using SQL

**Total records analyzed:** 714 passengers

---

## 📈 Key Performance Indicators

| KPI | Value |
|---|---:|
| Total Passengers | 714 |
| Survivors | 290 |
| Non-Survivors | 424 |
| Overall Survival Rate | 40.62% |

---

## 📊 Dashboard Visualizations

The dashboard includes the following visualizations:

### 1. Survival Rate by Gender

Compares the observed survival rates between female and male passengers.

### 2. Survival Rate by Passenger Class

Shows the observed survival rate across:

- 1st Class
- 2nd Class
- 3rd Class

### 3. Survival Rate by Age Group

Displays survival rates across the defined age groups:

- Child
- Teenager
- Young Adult
- Adult
- Senior

### 4. Survival Rate by Family Group

Analyzes survival rates based on family grouping:

- Alone
- Small Family
- Medium Family
- Large Family

### 5. Survival Rate by Embarkation Port

Compares observed survival rates across the embarkation categories:

- C
- S
- Q

---

## 🎛️ Interactive Filters

The dashboard provides filters for:

- Gender
- Passenger Class
- Age Group
- Embarkation Port

These filters allow users to explore the analysis from different perspectives.

---

## 🔍 Key Observations

Based on the analysis performed in Task 2:

- The dataset contains 714 passengers.
- 290 passengers survived.
- 424 passengers did not survive.
- The overall observed survival rate was 40.62%.
- Survival rates varied between female and male passengers.
- Survival rates varied across passenger classes.
- Different age groups showed different observed survival rates.
- Family groups showed different observed survival rates.
- Survival rates also varied across embarkation categories.

These observations describe patterns in the dataset and do not by themselves establish causal relationships.
